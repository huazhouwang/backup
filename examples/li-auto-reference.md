# 理想汽车车机界面参考

首页和设置页的风格参考理想 L 系列车机（OTA 5.x 中控屏）。参考图来自公开报道，没有放进仓库：

- IT之家《理想 L 系列车型 2024 年一季度 OTA 功能预告》：https://www.ithome.com/0/741/513.htm
  （分屏 / 全屏、桌面卡片、底栏左右两段、媒体卡片、天气卡片、车辆中心卡片）

从参考图里取的要点：

- 近黑底（约 #0A0B0D），卡片是扁平深灰（约 #1A1C20），圆角约 16dp，卡片之间 8dp 缝，没有投影和描边。
- 三列：左边车辆卡（上面大字档位 / 车速、车模、三个快捷图标，下面媒体条），中间地图，右边时间天气卡
  （大字时间、日期、逐小时天气、指南针、海拔）。我们没有地图和天气：中间换成壁纸画框，右边换成日出日落 + GPS 指南针。
- 底栏两段：左段只有图标（系统入口），右段是车控 / 文字按钮；我们右段放常用应用。
- 选中是蓝色（约 #3B76F6）实心块；文字白色 / 60% 白，数字用细字体。
